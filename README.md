# NexusTalent Scripts

TypeScript-based JavaScript library for the NexusTalent Microsoft Dynamics 365 Model-driven app.

## Features

- TypeScript-based form scripting
- Dynamic form field visibility
- Reusable candidate utility functions
- Unit testing with Jest
- ESLint code quality checks
- TypeScript type checking
- Webpack bundling
- Source map generation
- Dynamics 365 Xrm types
